# PRODUCT — 준현 헬퍼 제품 정의

이 문서는 **무엇을 만들고 왜 만드는지**를 정의하는 제품의 공식 사양 문서입니다.

확정되지 않은 내용을 기존 구현에서 가져와 채우지 않습니다.

## 1. 제품 이름

`CONFIRMED`

**준현 헬퍼**

저장소 이름은 `JunhyunHelper`이지만 사용자에게 보이는 공식 제품명은 **준현 헬퍼**입니다.

## 2. 제품 한 줄 정의

`CONFIRMED`

준현 헬퍼는 **Escape from Tarkov 플레이를 지원하는 데스크톱 헬퍼 프로그램**입니다.

현재 확정된 상위 기능은 퀘스트, 은신처, 필요 아이템, 탄약 표, 지도이며, 랫스캐너 기능은 후속 추가 대상으로 둡니다.

## 3. 대상 사용자

`CONFIRMED`

최초 설계 기준 사용자는 이 프로젝트의 사용자 본인입니다. 일반 사용자 확장 여부는 이후 별도로 결정합니다.

## 4. 상위 제품 범위

### FEATURE-001 — 퀘스트 목록

- 상태: `CONFIRMED`
- 사용자에게 퀘스트 목록을 조건에 맞게 보여줍니다.
- 사용자는 퀘스트를 완료 처리할 수 있습니다.
- 어떤 조건으로 목록을 필터링/정렬/표시할지는 아직 `OPEN`입니다.

### FEATURE-002 — 은신처 목록

- 상태: `CONFIRMED`
- 은신처 시설 목록을 보여줍니다.
- 사용자는 각 은신처 시설의 레벨을 설정할 수 있습니다.
- 시설별 세부 정보와 레벨 변경 UX는 아직 `OPEN`입니다.

### FEATURE-003 — 필요 아이템

- 상태: `CONFIRMED`
- 은신처 업그레이드 및 퀘스트에 필요한 아이템 목록을 보여줍니다.
- 사용자는 각 아이템의 보유 개수를 추가할 수 있습니다.
- 퀘스트 완료 상태와 은신처 시설 레벨 변화가 필요 수량에 어떻게 반영되는지는 아직 `OPEN`입니다.

### FEATURE-004 — 탄약 표

- 상태: `CONFIRMED`
- 사용자는 각 구경별 탄약 목록을 확인할 수 있습니다.
- 각 탄약의 정보와 수급처를 표로 확인할 수 있습니다.
- 정확한 컬럼, 정렬/필터, 수급처 표현 방식은 아직 `OPEN`입니다.

### FEATURE-005 — 지도

- 상태: `CONFIRMED`
- 사용자는 지도를 통해 각종 게임 정보를 확인할 수 있습니다.
- 지도를 미니맵 형식으로 띄워 인게임 중에도 사용할 수 있어야 합니다.
- 표시 정보의 종류, 미니맵 창 동작, 인게임 사용 UX는 아직 `OPEN`입니다.

### FEATURE-006 — 랫스캐너

- 상태: `PLANNED`
- RatScanner의 기능을 준현 헬퍼로 옮겨 넣는 것을 목표로 합니다.
- 현재 RatScanner 원본 프로그램이 정상 동작하지 않으므로 즉시 구현 대상이 아닙니다.
- 실제 이식 범위와 구현 방식은 RatScanner의 기능과 현재 동작 상태를 별도로 조사한 뒤 정의합니다.

## 6. 제품 요구사항

### REQ-001 — 퀘스트 진행 상태 관리

- 상태: `CONFIRMED`
- 요구 동작: 조건에 맞는 퀘스트 목록을 표시하고 사용자가 퀘스트를 완료 처리할 수 있어야 합니다.
- 관련 기능: `FEATURE-001`

### REQ-002 — 은신처 시설 레벨 관리

- 상태: `CONFIRMED`
- 요구 동작: 은신처 시설 목록을 표시하고 사용자가 각 시설의 현재 레벨을 설정할 수 있어야 합니다.
- 관련 기능: `FEATURE-002`

### REQ-003 — 필요 아이템과 보유 수량 관리

- 상태: `CONFIRMED`
- 요구 동작: 퀘스트 및 은신처 업그레이드에 필요한 아이템 목록을 표시하고 사용자가 아이템별 보유 개수를 기록할 수 있어야 합니다.
- 관련 기능: `FEATURE-003`

### REQ-004 — 탄약 정보 조회

- 상태: `CONFIRMED`
- 요구 동작: 구경별 탄약 목록과 각 탄약의 정보 및 수급처를 표 형태로 조회할 수 있어야 합니다.
- 관련 기능: `FEATURE-004`

### REQ-005 — 지도 정보 조회 및 인게임 미니맵 사용

- 상태: `CONFIRMED`
- 요구 동작: 지도에서 각종 정보를 조회할 수 있어야 하며, 지도를 미니맵 형태의 별도 표시로 인게임 중 사용할 수 있어야 합니다.
- 관련 기능: `FEATURE-005`

### REQ-006 — RatScanner 기능 통합

- 상태: `PLANNED`
- 요구 동작: RatScanner의 유용한 기능을 준현 헬퍼 내부 기능으로 통합합니다.
- 선행 조건: 현재 RatScanner 원본이 정상 동작하지 않는 원인을 포함해 실제 기능과 구현 가능성을 조사해야 합니다.
- 관련 기능: `FEATURE-006`

## 7. 기능 간 관계 — 아직 확정하지 않음

다음은 제품 동작에 큰 영향을 주지만 사용자가 아직 구체적으로 정의하지 않은 항목입니다.

- 퀘스트 완료 처리 시 필요 아이템 목록이 자동으로 변경되는가?
- 은신처 시설 레벨 변경 시 이후 업그레이드에 필요한 아이템만 계산하는가?
- 동일 아이템이 퀘스트와 은신처 양쪽에 필요할 때 수량을 어떻게 합산하는가?
- 사용자의 보유 개수를 전체 필요량에서 차감하여 부족 수량을 보여주는가?
- 퀘스트/은신처 진행 상태를 어떤 단위로 저장하고 복구하는가?

이 항목들은 기존 Tarkov-Helper의 동작으로 결정하지 않고 사용자와 별도로 확정합니다.
