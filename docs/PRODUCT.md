# PRODUCT — Tarkov Helper 제품 정의

이 문서는 **무엇을 만들고 왜 만드는지**를 정의하는 제품의 공식 사양 문서입니다.

현재는 제품 설계 초기 단계이므로, 확정되지 않은 내용을 기존 구현에서 가져와 채우지 않습니다.

## 2. 대상 사용자

`CONFIRMED`

최초 설계 기준 사용자는 이 프로젝트의 사용자 본인입니다. 일반 사용자 확장 여부는 이후 별도로 결정합니다.

## 3. 해결할 핵심 문제

`OPEN`

아직 확정하지 않았습니다.

제품 기능 목록보다 먼저 다음을 파악합니다.

- 실제 Tarkov 플레이 중/전/후 어느 시점에 프로그램을 쓰는가
- 사용자가 지금 직접 하고 있는 번거로운 작업은 무엇인가
- 잘못된 판단이 어떤 손해를 만드는가
- 어떤 정보를 빠르게 보고 싶어 하는가
- 어떤 판단을 프로그램이 대신 해주길 원하는가

## 8. 정보 정확성 원칙

`CONFIRMED`

- 기존 Tarkov-Helper에 표시되거나 구현되어 있다는 이유만으로 정보를 사실로 간주하지 않습니다.
- 게임 정보가 제품 동작에 영향을 주는 경우 출처와 갱신 방식을 별도로 정의해야 합니다.
- 불확실하거나 오래될 수 있는 정보는 검증 없이 제품 규칙으로 고정하지 않습니다.

## 9. 현재 제품 설계 질문

다음 대화의 출발점입니다.

**사용자가 Tarkov를 하면서 “이건 프로그램이 대신 해줬으면 좋겠다”고 느끼는 가장 대표적인 한 장면은 무엇인가?**

기능 이름을 먼저 정하기보다, 실제 상황과 사용자의 행동을 먼저 듣습니다.
