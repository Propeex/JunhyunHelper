# 준현 헬퍼 v1.15.0 릴리즈 노트

## 파밍 가이드가 레이드 중 파밍 판단을 지원합니다

v1.15.0에서는 기존의 레이드 시작 장비·수납 편집 기능에 **레이드 세션 기반 실시간 파밍 도우미**가 추가됩니다.

### 레이드 시작 / 종료

- 파밍 가이드의 현재 장비, 수납 상태와 잠금 설정을 기준으로 별도 레이드 세션을 시작합니다.
- 레이드 중 파밍 가이드 상태를 직접 수정해도 원래 working state나 프리셋을 자동으로 덮어쓰지 않습니다.
- 레이드 종료 시 레이드 시작 시점 상태로 복원됩니다.

### Scanner 연동 파밍 지시

Scanner가 인게임 상세보기에서 아이템을 확인하면 파밍 가이드는 현재 레이드 세션과 다음 정보를 함께 사용합니다.

- 현재 필요한 개수
- 상인 판매가
- 플리마켓 평균가
- 아이템 크기
- 현재 남은 수납 공간과 Tarkov 수납 필터
- 사용자가 잠근 아이템·가방·수납칸

판단 결과는 Mini Scanner에 보관 위치, 기존 아이템 교체 또는 버리기 형태로 표시됩니다.

### 명시적 수락

파밍 가이드의 추천은 자동으로 적용되지 않습니다.

- 설정의 `파밍 가이드 수락` 전역 단축키를 눌러야 현재 레이드 세션에 반영됩니다.
- 수락 전에 사용자가 장비·수납·잠금을 직접 바꾸면 이전 추천은 즉시 취소됩니다.
- 오래된 추천이 바뀐 inventory 상태에 적용되지 않도록 session revision을 검증합니다.

### F 잠금

파밍 가이드에서 아이템, 장비, 수납 영역 또는 빈 칸에 커서를 두고 `F`를 누르면 자동 판단에서 보호할 수 있습니다.

- 아이템 잠금: 자동 교체 대상에서 제외
- 리그/가방/보안 컨테이너 잠금: 해당 수납 공간과 내부를 자동 배치에서 제외
- 빈 칸 잠금: 자동 배치가 사용하지 않는 예약 공간
- 잠금은 프리셋/working state와 함께 저장됩니다.

사용자가 직접 drag/drop하는 동작은 잠금으로 막지 않습니다.

### T 테스트 스캔

파밍 가이드 검색 결과 아이템에 커서를 두고 `T`를 누르면 실제 Scanner와 동일한 snapshot과 판단 경로를 사용해 파밍 추천을 시험할 수 있습니다.

### 현재 파밍 우선순위

빈 공간에 합법적으로 들어가는 아이템은 먼저 수납합니다. 공간이 부족해 교체가 필요한 경우 현재 정책은 다음 순서로 비교합니다.

1. 현재 필요한 수량이 남아 있는 아이템
2. 더 높은 칸당 가치
3. 더 높은 총가치
4. 마지막 동률이면 더 작은 아이템

가치는 현재 Scanner가 제공하는 상인 판매가와 플리 평균가 중 높은 값을 사용합니다.

## 호환성

- Farming Guide state: schema v2, 기존 v1 파일 읽기 지원
- Scanner display settings: schema v10, 기존 v9 설정 자동 보존/migration
- 기존 파밍 가이드 loadout, preset, nested storage, 조립/개조 기능은 유지됩니다.

## 안전 경계

이 기능은 Tarkov 프로세스 메모리, 패킷 또는 내부 inventory를 읽지 않으며 게임 입력을 자동화하지 않습니다. 기존 Scanner와 마찬가지로 외부 화면 인식과 사용자의 명시적 조작만 사용합니다.
