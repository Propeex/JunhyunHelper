## Product

- 사용자는 최신 Scanner recognition source frame을 명시적으로 PNG export할 수 있어야 한다.
- 자동 screenshot 저장은 하지 않는다.
- one-shot in-game scan과 one-shot all-display test scan을 제공한다.
- 두 one-shot은 버튼이 아니라 global hotkey로 실행한다.
- Scanner ON/OFF도 global hotkey를 제공한다.
- 하나의 Scanner 설정 창에서 세 command의 gesture를 변경/disable한다.
- duplicate gesture는 저장하지 않는다.

## DEC-058

Scanner v1.3.0은 explicit 분석 이미지 export, one-shot DisplayTest, 3종 global hotkey를 제공한다.

- default: Ctrl+Shift+F10/F11/F12
- global registration lifetime = MainWindow
- settings schema v4
- v3 legacy one-shot gesture는 in-game one-shot으로 우선 보존
- 신규 key collision은 신규 command 쪽만 fallback
- automatic raw screenshot persistence 금지는 유지하되 explicit user export는 허용
- detector/OCR/visual confidence, top1/top2 margin, market 계산, `RequiredTotal` 의미 변경 없음
- 새 사용자 기능이므로 v1.3.0 MINOR
- partially supersedes DEC-051/055의 disk-persistence 및 single-hotkey surface

## Architecture / data flow

```text
MainWindow lifetime
→ ScannerCoordinator.AttachHotkeyHost
→ 3 × ScannerGlobalHotkeyService
→ one-shot Tarkov / one-shot DisplayTest / Scanner toggle

one-shot mode
→ ScannerCoordinator one-shot gate
→ stop/await continuous loop
→ ScannerRuntimeService.ScanOnceAsync(mode)
→ existing detector/OCR/visual resolver
→ Item ID/presentation
→ latest requested mode re-check
→ restore only if still requested
```

Recognition image:

```text
detector source frame
→ ScannerRecognitionDebugStore memory snapshot
→ diagnostic window overlay for inspection
→ explicit Image Save
→ raw source PNG only
```
