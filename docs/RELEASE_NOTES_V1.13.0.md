# 준현 헬퍼 v1.13.0

## 파밍 가이드 추가

- 기존 스캐너 탭 오른쪽에 `파밍 가이드` 탭을 추가했습니다.
- 레이드 출발 상태를 장비 / 수납 공간 / 검색·요약의 3개 영역에서 구성할 수 있습니다.
- 헤드셋, 헬멧, 얼굴 장비, 완장, 방탄복, 안경, 주무기 2개, 권총, 근접무기와 PMC 인식표를 다룹니다.
- 근접무기와 PMC 인식표는 레이드 프리셋과 별개의 고정 설정으로 유지됩니다.

## 실제 Tarkov 수납 구조 기반 편집

- 포켓, 리그, 특수 슬롯, 가방, 보안 컨테이너를 표현합니다.
- 리그·가방·보안 컨테이너의 실제 내부 grid 구조를 현재 검증된 Tarkov 아이템 데이터에서 읽습니다.
- 아이템은 실제 `가로 × 세로` 크기로 표시됩니다.
- 검색 결과에서 아이템을 드래그해 장비 슬롯이나 수납 grid에 놓을 수 있습니다.
- 드래그 중 `R` 키로 90도 회전할 수 있습니다.
- 배치 가능한 위치는 초록색, 불가능한 위치는 빨간색으로 표시합니다.
- grid 근처에서 놓으면 인접 cell로 스냅하고, 명백한 빈 공간에 놓은 기존 아이템은 제거합니다.
- 단순한 남은 cell 수가 아니라 실제 연속 공간을 기준으로 아이템 배치 가능 여부를 판단합니다.

## 장비 구성과 프리셋

- 장비별 실제 호환 슬롯과 교체형 방탄판 정보를 사용합니다.
- 장비 설정 창에서 호환 부품과 방탄판을 선택할 수 있으며, 하위 부품 슬롯도 이어서 설정할 수 있습니다.
- 현재 전체 출발 상태를 이름을 붙여 프리셋으로 저장하고 다시 불러올 수 있습니다.
- 프리셋은 착용 장비, 부착물, 방탄판, 수납 장비, 수납 아이템, grid 위치와 회전 상태를 함께 보존합니다.
- 불러온 프리셋을 수정하면 현재 상태를 원본 프리셋과 동일하지 않은 상태로 취급합니다.

## 현재 상태 요약

파밍 가이드 오른쪽 하단에서 다음 정보를 확인할 수 있습니다.

- 총 무게
- 사용 중인 수납 cell / 전체 수납 cell
- 파밍한 가치: 이번 버전에서는 아직 계산하지 않으며 `—`로 표시

## 이번 버전에 포함하지 않은 기능

이번 릴리즈는 향후 파밍 판단 기능의 기반이 되는 Loadout / Inventory Editor를 먼저 구축한 버전입니다. 다음 기능은 아직 포함하지 않았습니다.

- 아이템 가치 판단 정책
- 무엇을 주울지 추천
- 무엇을 버리거나 교체할지 추천
- Scanner 인식 결과와 실시간 파밍 추천 연결
- 실제 인게임 inventory grid 좌표의 실시간 1:1 동기화

파밍 가이드는 현재 사용자의 출발 장비와 수납 가능 공간을 정확히 구성·보존하는 역할에 집중합니다.
