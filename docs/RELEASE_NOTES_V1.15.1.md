# 준현 헬퍼 v1.15.1

## 파밍 가이드 실사용 회귀 수정

v1.15.1은 v1.15.0 파밍 가이드 레이드 도우미를 실제 플레이 기준으로 다듬는 PATCH 릴리즈입니다. 기존 프리셋·레이드 세션·Scanner 구조는 유지하면서 지시 수명주기, 장착 판단, 잠금 의미, 특수 슬롯과 UI 반응을 수정합니다.

### 새 스캔이 이전 미수락 지시를 교체합니다

- 한 번에 하나의 pending transaction만 유지하는 안전성 계약은 유지됩니다.
- 새 아이템이 확인되면 이전 미수락 지시는 상태에 반영하지 않고 폐기한 뒤 새 아이템 기준으로 다시 판단합니다.
- 더 이상 이전 지시를 먼저 수락하도록 요구하지 않습니다.
- 사용자가 장비·수납·잠금을 직접 바꾸면 기존 pending은 조용히 무효화됩니다.

Mini Scanner 지시는 다음처럼 짧게 표시됩니다.

- 보관: `[보관할 장소]에 보관`
- 수납 교체: `[보관할 장소]의 [기존 아이템]과 교체`
- 버리기: `버리기`
- 장착: `[장착할 장소]에 장착`
- 장착 교체: `[장착할 장소]의 [기존 아이템]과 교체`
- 수락 후: `반영 완료`

### 장비·부품·방탄판까지 판단합니다

레이드 도우미의 장착 후보가 일반 수납 공간에만 머물지 않습니다.

- 빈 헤드셋·헬멧·얼굴·완장·방탄복·안경·주무기·보조무기·권총 슬롯
- 리그·가방·보안 컨테이너 장비 슬롯
- 총기·헬멧 등 조립품의 재귀적인 부착물 슬롯
- 교체 가능한 방탄판 슬롯

빈 장착 대상이면 장착을 먼저 제안하고, 이미 아이템이 있는 경우에는 기존 파밍 우선순위로 교체 가치가 더 높은지 비교합니다.

### 특수 슬롯을 Tarkov 규칙대로 처리합니다

- canonical Game Content의 `specialSlot` type 분류를 특수 슬롯 호환성 기준으로 사용합니다.
- 호환되지 않는 일반 아이템은 특수 슬롯에 들어갈 수 없습니다.
- 호환 아이템은 일반 인벤토리 크기가 1×1보다 커도 특수 슬롯에서는 정확히 1칸을 차지합니다.
- 수동 drag/drop, 저장 상태 sanitizer, 화면 렌더링, 수납 사용량 표시와 raid advisor가 같은 규칙을 공유합니다.

### 잠금 의미와 수명을 정리했습니다

- 장비·가방·아이템 잠금은 **그 대상 자체를 자동 교체/제거하지 못하게 하는 보호**입니다.
- 잠긴 리그·가방·보안 컨테이너라도 내부의 잠기지 않은 빈 공간은 정상적인 자동 수납 후보로 사용할 수 있습니다.
- 잠긴 대상이 사용자의 직접 조작이나 수락된 추천으로 제거·교체되면 해당 대상 잠금도 같이 사라집니다.
- 빈 칸 잠금은 특정 아이템과 무관한 독립 예약 공간이므로 그대로 유지됩니다.
- F 잠금 토글에서 전체 페이지를 다시 렌더링하지 않아 실사용 반응성을 개선했습니다.
- 드래그 후 잠금 테두리가 다시 사라지던 재렌더 순서 문제를 수정했습니다.

### T 테스트 스캔과 UI

- 검색 결과의 `T` 테스트 스캔은 실제 Scanner snapshot과 동일한 파밍 판단 경로를 사용합니다.
- 테스트용 Mini Scanner 표시는 제한된 시간 후 사라지고 실제 스캔 표시와 경합하지 않습니다.
- 권총 슬롯을 안경 아래로 이동했습니다.
- 레이드 미시작 상태의 불필요한 설명 문구를 제거했습니다.
- 수납 도움말을 `R: 회전 · F: 아이템/장비/빈 칸 잠금`으로 단순화했습니다.
- `mod_*` 등 내부 슬롯 ID는 가능한 경우 사용자용 한국어 부품/방탄판 이름으로 변환합니다.

### 조립 이미지

총기·헬멧 외형은 임의 합성하지 않습니다.

현재 조립 상태의 아이템 구성과 source-backed preset/composed image의 구성이 정확히 일치할 때만 그 이미지를 사용하며, 정확한 근거가 없으면 기존 안전한 개별 이미지 표시를 유지합니다.

## 호환성

- Farming Guide state schema: v2 유지
- Scanner display settings schema: v10 유지
- Game Content schema: v10 유지
- 별도의 사용자 데이터 migration은 필요하지 않습니다.

## 안전 경계

Tarkov 프로세스 메모리·패킷·내부 inventory를 읽거나 게임 입력을 자동화하지 않습니다. Scanner가 확인한 외부 화면 정보와 사용자의 명시적 수락을 통해서만 레이드 세션 상태를 변경합니다.
