# Quest Reward Decision

상태: `CONFIRMED`

날짜: 2026-08-08

## 결정

준현 헬퍼는 현재 퀘스트 보상 전체를 별도 canonical model, importer, 저장 구조, 상세 UI로 구현하지 않습니다.

퀘스트 보상은 Escape from Tarkov 인게임 화면에서 쉽게 확인할 수 있고, 준현 헬퍼의 핵심 목적(최신 데이터 갱신, 퀘스트 진행 판정, 미래 필요 아이템/정리 필요, 은신처 진행, 탄약 비교)에 직접 필요하지 않습니다.

## 이유

보상 전체를 지원하려면 외부 데이터의 보상 유형을 별도로 분석하고 canonical model/importer/UI를 유지해야 합니다. 현재 사용자 가치에 비해 유지보수 비용과 제품 복잡도가 더 큽니다.

따라서 `있으면 좋을 수 있는 정보`라는 이유만으로 기능을 추가하지 않습니다.

## 영향

- 현재 Quest 상세에 이미 필요한 진행 정보(목표, 제출 아이템, 해금 조건, 선행 퀘스트, Wiki 등)는 유지합니다.
- Quest reward 전체 canonical model 작업은 현재 개발 우선순위와 미완료 작업 목록에서 제거합니다.
- 향후 사용자가 실제 필요성을 느끼고 요청할 경우에만 다시 제품 요구사항으로 검토합니다.
