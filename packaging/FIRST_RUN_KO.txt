준현 헬퍼 v1.17.0 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.17.0 파밍 가이드 판단 규칙 재구축
- 파밍 가이드 레이드 중 Scanner로 새로 확인한 아이템은 파밍 가이드가 해당 레이드에서 획득한 FIR 아이템으로 취급합니다. Scanner가 FIR 아이콘·색·문자를 따로 판독하거나 사용자에게 FIR 여부를 묻지 않습니다.
- 파밍 판단의 최우선 목표는 현재 퀘스트·은신처에 필요한 FIR 수량을 가능한 한 많이 충족하는 것입니다. 남은 필요 수량을 넘는 초과분에는 추가 우선순위를 부여하지 않습니다.
- FIR 목표가 같다면 최종적으로 보유하게 되는 모든 아이템의 평균 플리마켓 가치 합계가 가장 높은 상태를 선택합니다. 음식·음료·탄약·탄창·치료제·방어구·헤드셋 등 특정 종류에 자동 생존 우선순위를 주지 않습니다.
- 사용자가 고정한 아이템과 칸은 판단의 제약으로만 작동합니다. 고정 아이템 자체뿐 아니라 부모 컨테이너나 장착 장비를 움직여 간접적으로 위치를 바꾸는 계획도 허용하지 않습니다.
- 매 스캔마다 새 아이템만 빈칸에 끼워 넣는 방식이 아니라, 현재 이동 가능한 보유품과 새 아이템 전체를 대상으로 합법적인 최종 배치를 다시 계산합니다. 장비 슬롯, 가방·리그·보안 컨테이너, 컨테이너 안 컨테이너와 전용 수납 공간을 함께 고려합니다.
- 최종 배치는 실제 아이템 크기·회전·충돌·그리드 필터·중첩 관계·장비 호환·부착물·방어판·방탄복/방탄 리그 충돌·헬멧/헤드셋 호환·수량·고정 상태를 검증합니다.
- 부착물과 방어판을 포함해 최종 보유 가치와 무게를 계산합니다. 탄약·화폐처럼 사용자가 입력한 스택 수량은 필요 수량, 가치와 무게에 그대로 반영됩니다.
- 무게는 사용자가 설정한 힘 레벨 기준 최대 운반 중량을 넘지 않아야 하는 제약으로만 사용하며 아이템 우선순위 자체에는 영향을 주지 않습니다.
- 필요한 가격·무게·크기·호환 사실을 확인할 수 없을 때는 값을 0이나 임의 기본값으로 추정해 버리기·교체 같은 파괴적 지시를 만들지 않습니다.
- 글로벌 재배치 때문에 같은 수납 공간 안에서도 아이템 위치나 회전을 바꿔야 하면 지시에 '내부 재배치'가 표시됩니다.

검증
- Windows Release 빌드와 deterministic core tests를 실행합니다.
- win-x64 self-contained single-file publish 결과의 ProductVersion과 FIRST_RUN 버전을 검증합니다.
- 실제 published EXE를 실행해 Product UI, 파밍 가이드 글로벌 판단, 중첩 수납, 고정 ancestry, 전용 수납, 지도·Scanner 회귀 smoke를 수행합니다.
- 정상 Main Window 종료와 process 정리, portable root 오염 여부, release ZIP 구조와 SHA-256 manifest를 검증합니다.
- 별도의 Shutdown Race CI로 비동기 작업 중 종료 안정성도 검증합니다.
