준현 헬퍼 v1.1.2 — Windows x64

실행 방법
1. 받은 ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.1.2 주요 변경 — Scanner 제목 인식 회귀 수정
- v1.1.1 통합 Scanner가 현재 Tarkov 상세창 전체 대신 내부의 작은 사각 영역을 상세창으로 잘못 선택할 수 있던 문제를 수정했습니다.
- 현재 한국어 클라이언트에서 관측한 상세창 외곽 구조를 기준으로 detector geometry를 바로잡았습니다.
- 상세창 후보는 외곽 상/하/좌/우 테두리와 우상단 닫기 영역을 함께 만족해야 합니다.
- 구조 점수가 비슷한 경우 내부의 작은 사각형보다 실제 외곽 상세창을 우선합니다.
- 제목 OCR 영역을 상세창 최상단 제목 한 줄로 좁혀, 바로 아래 '교환용 물품 > 의료용품' 같은 분류 행이 OCR 입력에 섞이지 않도록 수정했습니다.
- 더 엄격한 외곽 검증에서도 위치를 놓치지 않도록 픽셀 단위 탐색 정밀도를 높였고, 닫기 영역/테두리 조건을 순차적으로 검사해 불필요한 연산을 줄였습니다.
- OCR matcher의 confidence/margin 기준은 완화하지 않았습니다. 확신이 부족하면 계속 식별을 보류합니다.
- Scanner 탭 UI와 Mini Scanner 표시 방식은 v1.1.1과 동일합니다.

Scanner UI
- 상단 바 왼쪽에 '스캐너'와 '테스트' 버튼이 있습니다.
- 상단 바 오른쪽의 전체 아이템 카탈로그 수동 갱신 버튼은 '아이템 목록 최신화'입니다.
- 표시 정보 체크박스 아래의 '최근 인식 기록'에서 OCR 문자열, 가장 가까운 공식 아이템 후보, 유사도, 후보 간 차이, 최종 식별 성공/보류 판단을 확인할 수 있습니다.
- Foundation 검증 도구는 일반 Scanner 탭에서 보이지 않으며 개발 진단용 내부 경로만 유지합니다.
- Mini Scanner는 별도 편집 모드 없이 보이는 동안 직접 드래그해 위치를 옮길 수 있고, 드래그를 마치면 위치를 저장합니다.
- Mini Scanner는 Topmost/no-activate를 유지하며 게임 창의 키보드 포커스를 가져가지 않습니다.

Scanner 동작
- '스캐너 ON/OFF'는 EscapeFromTarkov 게임 창을 찾아 Borderless client-area를 대상으로 실시간 감지합니다.
- '테스트 ON/OFF'는 연결된 전체 디스플레이를 대상으로 같은 감지 파이프라인을 실행합니다. Tarkov 전체 스크린샷을 바탕화면/이미지 뷰어에 띄운 상태에서 기능을 확인할 수 있습니다.
- 두 모드는 동시에 실행되지 않습니다. 테스트 모드는 프로그램을 다시 실행하면 자동으로 OFF입니다.
- 상세창 구조를 먼저 감지하고 안정화한 뒤 제목 영역만 한국어 Windows OCR로 읽습니다.
- OCR 결과는 전체 Tarkov 아이템 카탈로그와 보수적으로 대조하며 확신이 부족하면 아이템을 표시하지 않습니다.
- Item ID가 확정되면 기존 준현 헬퍼 데이터에서 아이템 이름, 로컬 아이콘, 상인/플리 가격, 슬롯당 가격, 현재 필요한 수량을 가져와 Mini Scanner에 표시합니다.
- 실제 scan 순간에는 외부 API를 호출하지 않습니다. 아이콘도 scan 중 새로 다운로드하지 않습니다.
- 게임 메모리 읽기, DLL injection, 패킷 가로채기, 아이콘 기반 식별은 사용하지 않습니다.

Scanner 검증 상태
- 과거 Scanner Lab에서 텍스트 OCR, 상세보기 이미지 감지, 전체 Tarkov 스크린샷 감지를 검증했습니다.
- v1.1.2에서는 사용자가 제공한 현재 클라이언트 `Ophthalmoscope 검안경` 상세창을 기준으로 v1.1.1의 잘못된 내부 영역 선택과 분류 행 OCR 문제를 재현한 뒤 detector/제목 ROI를 수정했습니다.
- 첨부 화면에 새 제목 ROI를 적용하면 `Ophthalmoscope 검안경` 한 줄만 포함되고 아래 분류 행은 제외됩니다.
- Windows Release build, 자동 회귀 테스트, self-contained publish, 실제 EXE 기본 UI/Map/MiniMap smoke를 통과한 코드만 정식 배포합니다.
- 최신 Tarkov Borderless에서의 실제 인게임 E2E는 공개 릴리즈 후 사용자 환경에서 Scanner 로그와 함께 계속 검증·보정합니다.

Scanner 진단 로그
- %LocalAppData%\JunhyunHelper\logs\scanner.log
- 최대 약 2MB에서 이전 로그를 scanner.log.1로 회전합니다.
- 캡처 상태, 감지 후보, OCR 제목 문자열, 매칭 결과/confidence를 기록합니다.
- 전체 스크린샷이나 원본 화면 픽셀은 로그에 저장하지 않습니다.
- Scanner 탭의 최근 인식 기록은 이 개발자 로그를 그대로 노출하지 않고 OCR/후보/유사도/판단만 사용자용으로 정리해 보여줍니다.

Scanner 데이터/설정
- 전체 아이템 카탈로그: %LocalAppData%\JunhyunHelper\scanner\catalog
- Scanner 설정: %LocalAppData%\JunhyunHelper\scanner-settings.json
- Scanner 설정 복구본: %LocalAppData%\JunhyunHelper\scanner-settings.json.bak
- Scanner 카탈로그는 켜기/명시적 최신화/필요한 프로필 전환 시 준비하며 실제 인식 중에는 로컬/메모리 데이터만 사용합니다.

프로그램 업데이트
- 새 정식 버전이 있을 때만 업데이트 확인창을 표시합니다.
- 사용자가 동의하면 새 Windows x64 ZIP과 SHA256SUMS.txt를 내려받습니다.
- 공개된 SHA-256과 다운로드 파일이 일치하고 패키지 구조가 정상인지 확인한 뒤에만 교체를 시작합니다.
- 교체할 때 현재 준현 헬퍼가 종료되고, 임시 updater 프로세스가 프로그램 파일을 교체한 뒤 새 버전을 자동으로 다시 실행합니다.
- 업데이트 확인 실패나 인터넷 연결 문제는 프로그램 실행을 막지 않습니다.
- 다운로드/검증 실패 시 기존 프로그램 파일을 변경하지 않습니다.
- 실제 파일 교체 중 실패하면 기존 프로그램 파일을 가능한 범위에서 복구하고 기존 버전을 다시 실행합니다.

배포 형태
- 설치 프로그램이 필요 없는 portable/self-contained Windows x64 빌드입니다.
- .NET/WPF/SQLite/Skia 런타임은 '준현 헬퍼.exe'에 포함됩니다.
- 지도 시스템이 경로로 직접 읽는 검증된 파일만 Assets 폴더에 둡니다.
- 실행 폴더 루트에는 '준현 헬퍼.exe', 이 안내문, Assets 폴더만 두는 것을 기준으로 합니다.
- 별도 .NET 설치나 관리자 권한은 필요하지 않습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

사용자 데이터
- 사용자 진행 데이터: %LocalAppData%\JunhyunHelper\user.db
- 게임 데이터: %LocalAppData%\JunhyunHelper\content
- 이미지 캐시: %LocalAppData%\JunhyunHelper\image-cache
- 지도 제품 설정: %LocalAppData%\JunhyunHelper\map-product-settings.json(.bak)
- 탄약 즐겨찾기: %LocalAppData%\JunhyunHelper\ammo-favorites.json(.bak)
- Scanner 설정/카탈로그: %LocalAppData%\JunhyunHelper\scanner-settings.json(.bak), scanner\catalog\
- 프로그램 업데이트 임시 파일: %LocalAppData%\JunhyunHelper\updates\pending
- 프로그램 일반 오류 로그: %LocalAppData%\JunhyunHelper\logs\startup.log
- Scanner 진단 로그: %LocalAppData%\JunhyunHelper\logs\scanner.log(.1)
- 프로그램 파일 교체와 사용자 데이터는 분리되어 있으므로 기존 Profile / Quest / Inventory / Hideout / Map 설정 / Ammo 즐겨찾기는 유지됩니다.

데이터 호환성
- Content schema: v7
- Readable Content schemas: v3, v4, v5, v6, v7
- user.db SQLite schema: v1
- v1.1.1 → v1.1.2 필수 Game Content 업데이트: 없음
- v1.1.1 → v1.1.2 user.db migration: 없음

정확도 / 안전성
- Quest/Hideout/Needed Items의 기존 제품 의미는 v1.1.1과 동일합니다.
- Scanner는 오탐보다 미탐을 우선합니다. 불확실한 OCR/Item ID는 강제로 선택하지 않습니다.
- Scanner matcher threshold와 top1/top2 margin 정책은 v1.1.1에서 완화하지 않았습니다.
- Game Content update와 Program update는 서로 다른 subsystem입니다.
- Runtime GPT/AI 의존성은 없습니다.

버전 정책
- 새 기능 추가: MINOR +1, PATCH는 0으로 초기화합니다.
- 기존 기능 수정·보완·버그 수정·성능/안정성 개선: PATCH +1입니다.
- v1.1.2는 v1.1.1 Scanner의 상세창/제목 ROI 회귀 버그 수정이므로 PATCH 릴리즈입니다.
