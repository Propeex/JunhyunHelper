준현 헬퍼 v1.6.0 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.6.0 주요 변경 — Scanner 사용 화면·Mini Scanner·교정 작업 흐름 정리
- Scanner 일반 화면은 '스캐너 ON/OFF', '설정', '고급' 세 동작을 중심으로 정리했습니다.
- 일반 화면 아래쪽은 아이템 검색과 Scanner 인식 로그를 나란히 확인하는 구조로 변경했습니다.
- 아이템 검색은 현재 내려받은 전체 Tarkov 아이템 카탈로그를 사용하며 검색 중 네트워크 요청을 만들지 않습니다.
- 검색한 아이템은 아이콘, 이름, Tarkov Wiki, 플리마켓 평균가, 최고 상인 판매가, 현재 필요 개수를 확인할 수 있습니다.
- 기존 1회 인게임 스캔, 1회 테스트 스캔, Scanner ON/OFF 전역 단축키 기능은 유지됩니다.
- Mini Scanner는 아이템 아이콘과 이름을 항상 상단에 고정하고, 상인 판매가·플리 평균가·상인 칸당 가격·플리 칸당 가격·필요 개수의 표시 여부와 순서를 설정할 수 있습니다.
- Mini Scanner의 상인 가격은 '최고 상점가' 같은 일반 문구 대신 가능한 경우 실제 최고가 상인 이름과 가격을 함께 표시합니다.
- Scanner '고급' 화면은 테스트 Scanner, 현재 결과 교정, 교정 데이터 관리처럼 실사용 진단 기능 위주로 정리했습니다.
- 교정 화면은 큰 원본 스크린샷도 창 안에 맞게 자동 축소해 보여 주되 Ground Truth 좌표는 원본 이미지 좌표계로 저장합니다.
- 상세창·닫기 X·돋보기·아이템명 ROI는 드롭다운 대신 이미지 위 후보 사각형을 직접 클릭해 선택할 수 있습니다.
- 후보가 없으면 '없음' 또는 직접 영역 지정을 사용할 수 있습니다.
- 저장된 Scanner Case를 교정 데이터 관리에서 다시 열어 기존 Ground Truth를 재검토하고 수정할 수 있습니다.
- Scanner 설정 파일은 schema v6으로 자동 마이그레이션되며 기존 단축키·표시 설정·OCR 사용자 교정 규칙을 가능한 한 보존합니다.
- 배포 ZIP 이름과 압축 해제 폴더 이름을 버전과 분리했습니다. 앞으로 정식 배포 파일은 'Junhyun-Helper.zip', 내부 최상위 폴더는 '준현 헬퍼'를 사용합니다.

Scanner 인식 안전 계약
- false positive보다 miss를 선호합니다.
- structural floor 0.34, HEADER_FRAME_LOCKED 0.68, continuous candidate cap 8, one-shot candidate cap 12를 이번 버전에서 완화하지 않았습니다.
- Item ID가 확정되기 전에는 가격·필요 개수 같은 mapped data를 identity 증거로 사용하지 않습니다.
- Scanner 인식 중 네트워크 요청, 게임 메모리 읽기, DLL injection, packet interception을 사용하지 않습니다.

사용자 데이터
- 프로필, 진행도, Scanner 설정, 교정 데이터, 로그 등 변경 가능한 사용자 데이터는 프로그램 폴더가 아니라 %LocalAppData%\JunhyunHelper 아래에 보관됩니다.
- 프로그램 업데이트로 기존 사용자 진행도와 Scanner Ground Truth를 덮어쓰지 않습니다.
