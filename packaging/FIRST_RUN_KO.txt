준현 헬퍼 v1.17.2 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.17.2 변경
- 새 기능 추가나 성능 최적화 없이 현재 제품의 불필요한 잔재와 중복 경로를 정리했습니다.
- MainWindow, Profile, Ammo, Quest/Hideout/Items 검색, Scanner/Mini Scanner에서 숨은 구형 UI, runtime rebinding, proxy control, 도달 불가능한 handler와 이전 기능 잔재를 제거했습니다.
- Ammo와 Scanner의 현재 UI 소유권을 XAML/명시적 lifecycle로 정리하고, 검증 smoke가 제품 UI를 대신 만들어 통과시키지 않도록 계약을 정리했습니다.
- 현재 updater는 stable 'Junhyun-Helper.zip' 패키지와 stable wrapper root만 인정하며, 오래된 전환기용 package/root fallback을 제거했습니다.
- 현재 release/schema 사실값은 PROJECT_STATE를 기준으로 관리하도록 문서 중복과 오래된 current-state 표현을 정리하고 Documentation Consistency 검사를 강화했습니다.
- 정리 과정에서 발견한 Items 정리 필요 표시 갱신 회귀를 수정하고, 제거된 구조를 다시 요구하던 구형 회귀 테스트를 현재 제품 계약에 맞췄습니다.
- Quest, Hideout, Items, Ammo, Map/MiniMap, Scanner 인식/검색/교정/진단의 현재 제품 기능과 Map donor 계약은 유지합니다.
