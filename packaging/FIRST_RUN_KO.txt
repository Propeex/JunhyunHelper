준현 헬퍼 v1.12.1 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.12.1 김태영 PC 진단 UX 보완
- 진단 시작 확인 문구를 `혹시 김태영 본인?`으로 단순화했습니다.
- `예`를 누른 뒤 진단 ZIP을 만드는 동안 indeterminate 진행 바를 표시합니다.
- 완료 안내는 `진단 완료.` / `파일을 hyune4784@naver.com 으로 보내주세요.` 두 문장만 표시합니다.
- 완료 안내를 닫으면 기본 브라우저에서 네이버 메일 쓰기 페이지를 자동으로 엽니다. ZIP 자동 첨부/자동 전송은 하지 않습니다.

v1.12.0 Quest 선행조건 / 검색 UI / 김태영 PC 진단
- Trader Loyalty Level이 이미 다음 단계로 올라간 뒤 과거 side-task pool 48개가 한꺼번에 `확인 필요`로 바뀌던 Quest 선행조건 회귀를 수정했습니다. 현재 게임의 단계형 task-pool 규칙과 다음 Trader LL 도달 시 다음 그룹이 열리는 동작을 함께 반영합니다.
- 은신처 검색창의 `×`가 다른 검색창보다 아래에 보이던 위치 오차를 수정했습니다.
- 메인 좌측 상단 프로필 이미지를 클릭하면 `김태영 PC 진단`을 실행할 수 있습니다. 본인 확인 후 디스플레이/GPU/HDR/드라이버/Scanner·캡처 관련 상태와 비교 화면을 로컬 ZIP으로 수집하며 자동 전송하지 않습니다. 완료되면 바탕화면 ZIP을 지정된 이메일로 보내 달라고 안내합니다.

v1.11.4 MiniMap 마커 lifecycle / Mini Scanner 우클릭 수정
- Main Map에서 지도를 바꾼 뒤 MiniMap을 처음 켜도 이전 지도가 잠깐 보이지 않고 현재 선택한 지도를 첫 생성부터 사용합니다.
- MiniMap의 Transit 탈출구를 포함한 실제 extract marker 렌더링 경로를 재점검하고, published EXE에서 실제 Transit 마커가 생성되는지 직접 검증합니다.
- MiniMap 일반 마커가 비동기 refresh 취소 타이밍 때문에 잠깐 보였다가 모두 사라질 수 있던 경로를 보강했습니다. 표시 대상 데이터가 있는데 레이어만 비면 이미 로드된 데이터에서 표준 마커 레이어를 직접 복구합니다.
- Player Marker Size 변경은 플레이어 마커만 수정하며 Name Size와 MiniMap Marker Size 등 다른 표시 설정을 다시 적용하거나 초기화하지 않습니다.
- Mini Scanner를 우클릭해도 `현재 결과 교정` 컨텍스트 메뉴가 더 이상 표시되지 않습니다. 좌클릭 드래그와 교정 데이터 단축키는 그대로 유지됩니다.

v1.11.3 검색창 / 지도 마커 / Scanner 교정 UX 및 evidence 수정
- 아이템과 은신처 검색창은 실제 페이지 lifecycle에서 공통 inline `×`를 안정적으로 연결합니다. 검색어가 없을 때는 숨기고, 입력 중에만 표시되며 클릭하면 검색어를 지우고 포커스를 유지합니다.
- 지도 마커 패널은 큰 창에서 사용 가능한 세로 공간을 정상적으로 사용해 하단 탈출구 항목이 잘리지 않게 했습니다. 실제로 내용이 넘칠 때만 내부 스크롤이 나타납니다.
- Scanner 교정 스크린샷은 마우스 휠로 확대/축소할 수 있으며 확대 후 스크롤로 위치를 확인할 수 있습니다. Ground Truth/직접 지정 좌표는 항상 원본 이미지 픽셀 좌표를 유지합니다.
- 교정 데이터 저장 시 동일한 아이템 화면임이 확인되는 최근 OCR/matcher 분석 결과를 보존해 `NOT_RUN`으로 덮어써지던 진단 timing 문제를 수정했습니다. 실제 Scanner 판정 threshold는 완화하지 않았습니다.

v1.11.2 Scanner 교정 저장 / 검색창 / 지도 플레이어 방향 수정
- `교정 데이터 추가` 단축키는 교정 evidence만 저장하고 Mini Scanner에 `저장 완료`만 표시합니다. Saved Cases 창을 자동으로 열거나 레이드 화면의 focus를 빼앗지 않습니다.
- 아이템과 은신처 검색창은 퀘스트 검색창과 같은 inline `×` 동작을 사용합니다. 검색어가 없을 때는 보이지 않고, 입력 중에만 표시됩니다.
- Factory를 포함한 지도 플레이어 방향은 위치에 쓰는 맵별 좌표 변환과 동일한 기준으로 계산합니다. Main Map과 MiniMap 모두 같은 방향을 사용합니다.
- Factory/Labs/Reserve/Labyrinth 및 현재 전체 map player transform을 회귀 검증 대상으로 추가했습니다.

v1.11.1 Scanner 설정 / 검색 / 교정 저장 UX 수정
- Scanner 설정에 기존 탄약 `주워야 함` 판단을 표시/숨김 및 정보 순서 항목으로 추가했습니다.
- 아이템과 은신처 탭 검색창에 검색어를 즉시 지우는 `×` 버튼을 추가했습니다.
- `교정 데이터 추가` 단축키로 Saved Case 저장에 성공하면 Mini Scanner에서 `저장 완료`를 잠시 표시합니다.
- v1.11.0의 탄약 판단, Ammo Pack, Hideout FIR, Map/MiniMap 유지보수와 주요 제품 계약을 함께 재점검했습니다.
- Scanner 설정/검색 지우기/저장 완료 피드백을 실제 published EXE smoke에서 직접 검증하도록 회귀 게이트를 보강했습니다.

v1.11.0 Scanner / Map 유지보수 및 탄약 판단
- MiniMap 첫 실행 지도 동기화, Marker 표시 설정 보존 및 marker layer 복구를 보강했습니다.
- Hideout FIR 의미와 Scanner 교정 데이터 단축키를 수정·추가했습니다.
- 탄약/Ammo Pack은 관통력과 현재 직접 구매 가능 상태를 기준으로 pickup 판단합니다.
