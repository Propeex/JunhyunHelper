준현 헬퍼 v1.16.1 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.16.1 안정성·복구력 보완
- 파밍 가이드 저장 파일이 일부만 손상되거나 과거 비정상 값이 섞여 있어도 가능한 상태는 보존하면서 안전하게 정상화하도록 복구를 강화했습니다.
- 프로그램 시작 시 구버전 게임 데이터 형식을 자동 갱신하는 동안 사용자가 다른 프로필로 전환하더라도 이전 프로필의 갱신 결과가 새 프로필 화면에 적용되지 않도록 비동기 상태 경계를 강화했습니다.
- 관련 저장 복구·프로필 상태 일관성 회귀 테스트를 추가하고 Windows published EXE의 UI·지도·종료·패키지 경로를 다시 검증합니다.

v1.16.0 파밍 가이드 판단 규칙·수량·무게 개선
- 파밍 가이드 판단을 가중치 점수가 아니라 제약 → 중요도 → 상황 대처의 결정적 규칙으로 정리했습니다.
- 특별 우선순위는 Found in Raid가 실제로 필요한 아이템에만 적용합니다. 비-FIR 필요품은 일반 경제 loot과 동일하게 판단합니다.
- 경제 가치는 평균 플리마켓가로 통일하고, 공간을 만들기 위해 기존 물품을 버려야 할 때는 실제 희생되는 전체 물품의 플리마켓 가치와 비교합니다.
- 장비는 가격 때문에 자동 교체하지 않습니다. 방탄복·헬멧은 방탄등급, 헤드셋은 청취거리, 일반 리그·가방·보안 컨테이너는 수납량, 방탄 리그는 방탄등급 우선 후 동급일 때 수납량을 대표 기준으로 사용합니다.
- 수납 장비 교체 시 잠긴 아이템은 버리지 않고 새 장비 내부에서 합법적으로 재배치합니다. 예약 칸은 기존 좌표가 아니라 연결된 모양과 용량을 새 장비에 승계하며, 승계할 수 없으면 교체하지 않습니다.
- 탄약과 화폐처럼 개수가 중요한 스택 아이템은 Mini Scanner에서 개수를 입력한 뒤 Enter를 누르면 파밍 판단을 계속합니다.
- 파밍 가이드 화면의 스택 아이템에는 개수를 표시하고, 더블클릭하여 개수를 수정할 수 있습니다. 수량은 필요 개수·가치·무게 계산에 반영됩니다.
- 우측 하단 무게 표시를 클릭하면 힘 레벨을 입력할 수 있습니다. 현재 무게와 힘 레벨 기준 최대 운반 중량을 표시하고 최종 상태가 한계를 넘는 파밍 지시는 차단합니다.
- 힘 스킬은 현재 Tarkov 기준 기본 최대 운반 중량 77 kg, 레벨당 +0.6%, Elite 약 100 kg을 사용합니다. Elite에서는 주무기 1·2와 권총 슬롯의 무게를 제외합니다.
- MiniMap의 NumPad 0~5 직접 층 선택 기능은 제거했습니다. 기존에 설정 가능한 위/아래 층 이동 단축키는 유지합니다.
