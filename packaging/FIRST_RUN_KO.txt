준현 헬퍼 v1.15.3 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.15.3 파밍 가이드 수납·테스트 보완
- 일반 보관 아이템의 노란색 테두리를 제거했습니다. F로 잠근 아이템만 노란색 테두리로 표시됩니다.
- Key tool처럼 실제 Tarkov 데이터에 내부 수납칸이 정의된 특수 컨테이너도 상세 내부 공간을 열어 사용할 수 있습니다.
- 특정 컨테이너 이름을 하드코딩하지 않고 현재 Game Content의 실제 grid 크기와 allowed/excluded item/category filter를 따릅니다.
- 보안 컨테이너 안 특수 컨테이너, 컨테이너 안 컨테이너도 기존 ParentInstanceId 구조로 재귀적으로 관리합니다.
- 검색 결과에 마우스를 올리고 T를 누르는 테스트 스캔이 검색창 포커스 때문에 무시되던 문제를 수정했습니다.
- Scanner가 꺼져 있거나 재시작 뒤 아직 초기화되지 않았어도 테스트 스캔은 같은 모드의 정상 로컬 Scanner 캐시를 필요 시 불러와 실제 파밍 판단 경로를 사용합니다.
- 총기 부착물·헬멧 부착물·방탄판 같은 장비 내부 편집은 계속 제공하지 않습니다.

v1.15.2 파밍 가이드 장비 완제품 모델
- 총기·헬멧·방탄복 등 장비를 내부 부품을 따로 관리하지 않는 완제품 하나로 처리합니다.
- 총기 부착물·헬멧 부착물·방탄판 편집 UI와 장비 내부 장착/교체 파밍 지시를 제거했습니다.
- 주무기·권총·헬멧·방탄복·리그·가방·보안 컨테이너 같은 최상위 장비 칸 장착/교체 지시는 그대로 유지합니다.
- 저장된 예전 장비 개조 상태는 로딩 시 장비의 root Item ID만 남도록 정리됩니다.
- v1.15.2에서는 nested storage 상세를 가방/리그로 제한했으며, 이 제한은 v1.15.3에서 실제 source-backed storage grid가 있는 모든 저장 컨테이너로 확장되었습니다.
- 장비 이미지는 가능한 경우 canonical default preset의 완제품 이미지를 우선 사용하고 임의 조립 이미지는 만들지 않습니다.
- 무기/장비 아이콘의 내부 여백을 줄여 실제 장비 칸을 더 크게 채우도록 표시합니다.

v1.15.1 파밍 가이드 실사용 수정
- 새 아이템을 스캔하면 수락하지 않은 이전 파밍 지시는 자동으로 폐기하고 새 지시로 교체합니다.
- Mini Scanner 파밍 지시를 보관 위치/교체/버리기/장착 중심의 짧은 문구로 정리하고, 수락 후에는 '반영 완료'를 표시합니다.
- 빈 장비칸뿐 아니라 총기·헬멧 부품 슬롯과 방탄판 슬롯도 장착 판단에 포함했습니다. 이 내부 장비 판단은 v1.15.2에서 제거되고 최상위 장비 칸 판단만 유지됩니다.
- 특수 슬롯은 현재 Tarkov 데이터의 specialSlot 분류를 따르며, 허용된 아이템은 일반 인벤토리 크기와 관계없이 특수 슬롯 1칸을 사용합니다.
- 리그·가방·보안 컨테이너 잠금은 장비 자체의 자동 교체를 막지만 내부 빈 공간의 정상적인 자동 수납은 허용합니다.
- 잠긴 대상이 제거·교체되면 해당 대상 잠금은 함께 사라지고, 빈 칸 잠금은 독립적인 예약 공간으로 유지됩니다.
- F 잠금 시 전체 파밍 가이드 화면을 다시 그리지 않아 잠금 반응과 표시 안정성을 개선했습니다.
- 검색 결과의 T 테스트 스캔은 실제 Scanner와 같은 판단 경로를 사용하되 잠시 후 자동으로 사라집니다.

v1.15.0 파밍 가이드 레이드 도우미
- 파밍 가이드에서 '레이드 시작'을 누르면 현재 장비·수납·잠금 상태를 기준으로 독립적인 레이드 세션을 시작합니다.
- Scanner가 확인한 아이템에 대해 현재 필요한 개수, 상인 판매가, 플리 평균가, 차지하는 칸과 현재 수납 상태를 함께 고려해 파밍 지시를 표시합니다.
- 지시는 Mini Scanner에 표시되며 사용자가 설정한 '파밍 가이드 수락' 단축키를 눌러야 실제 파밍 가이드 세션 상태에 반영됩니다.
- 레이드 종료 시 레이드 중 변경을 폐기하고 시작 시점 상태로 돌아갑니다. 레이드 중 임시 변경은 원래 프리셋을 덮어쓰지 않습니다.
- 파밍 판단은 현재 필요한 아이템을 우선하고, 필요 여부가 같으면 칸당 가치와 총가치를 비교합니다.

v1.14.1 파밍 가이드 수납 배치 안전성 수정
- product-owned exact layout은 layout identity, grid 개수와 각 grid index의 가로×세로 signature가 current Game Content와 정확히 일치할 때만 사용합니다.
- signature가 다르면 수납 mechanics는 current Game Content를 유지하면서 화면 배치만 compact fallback으로 전환합니다.

v1.14.0 파밍 가이드 조립·총기 개조·수납 배치 강화
- 당시 총기·헬멧·방어구의 내부 부착물/방탄판 편집 기능을 도입했으며, 이 사용자 개조 기능은 v1.15.2에서 제거되었습니다.
- nested storage와 source-backed storage layout mechanics는 현재도 유지됩니다.
