준현 헬퍼 v1.6.1 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.6.1 주요 변경 — Scanner 안정성·레이아웃·로그 관리 보완
- 데이터 업데이트에서 이미 최신인 정상 Scanner 캐시를 '최신 데이터 다운로드 실패'로 잘못 안내하던 상태 판정 오류를 수정했습니다.
- 실제 Scanner 갱신 실패가 발생해도 같은 게임 모드의 검증된 정상 캐시가 있으면 인식을 계속 사용할 수 있으며, 불필요한 경고 팝업 대신 상태로만 알립니다.
- Scanner 필수 아이템 identity 데이터와 보조 영문명·상인 표시명 다운로드를 분리해 보조 데이터 장애가 전체 카탈로그 갱신 실패로 번지지 않도록 했습니다.
- 필수 Scanner 데이터 요청에는 요청별 timeout과 제한된 retry를 적용해 일시적인 네트워크·서버 오류에 대한 복원력을 높였습니다.
- Scanner 고급 창을 내용 높이에 맞춰 배치하도록 수정해 DPI·글꼴·Windows 창 장식 차이에서도 버튼이 잘리지 않도록 했습니다.
- Scanner runtime 로그는 7일 보존 정책과 기존 용량 제한을 함께 적용해 오래된 로그가 자동으로 정리됩니다.
- 사용자가 직접 검토·교정한 Scanner Ground Truth는 자동 로그 삭제 대상에서 제외되며 계속 보존됩니다.
- Scanner 아이템 검색 시 결과 행에 필요하지 않은 전체 표시 데이터 계산을 반복하지 않도록 검색 경로를 최적화했습니다.

Scanner 인식 안전 계약
- false positive보다 miss를 선호합니다.
- structural floor 0.34, HEADER_FRAME_LOCKED 0.68, continuous candidate cap 8, one-shot candidate cap 12를 이번 버전에서 완화하지 않았습니다.
- Item ID가 확정되기 전에는 가격·필요 개수 같은 mapped data를 identity 증거로 사용하지 않습니다.
- Scanner 인식 중 네트워크 요청, 게임 메모리 읽기, DLL injection, packet interception을 사용하지 않습니다.

사용자 데이터
- 프로필, 진행도, Scanner 설정, 교정 데이터, 로그 등 변경 가능한 사용자 데이터는 프로그램 폴더가 아니라 %LocalAppData%\JunhyunHelper 아래에 보관됩니다.
- 프로그램 업데이트로 기존 사용자 진행도와 Scanner Ground Truth를 덮어쓰지 않습니다.
