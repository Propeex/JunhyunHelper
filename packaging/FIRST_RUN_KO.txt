준현 헬퍼 v1.15.0 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.15.0 파밍 가이드 레이드 도우미
- 파밍 가이드에서 '레이드 시작'을 누르면 현재 장비·수납·잠금 상태를 기준으로 독립적인 레이드 세션을 시작합니다.
- Scanner가 확인한 아이템에 대해 현재 필요한 개수, 상인 판매가, 플리 평균가, 차지하는 칸과 현재 수납 상태를 함께 고려해 보관·교체·버리기 지시를 표시합니다.
- 지시는 Mini Scanner에 표시되며 사용자가 설정한 '파밍 가이드 수락' 단축키를 눌러야 실제 파밍 가이드 세션 상태에 반영됩니다.
- 수락 전 사용자가 장비·수납·잠금 상태를 직접 바꾸면 이전 지시는 자동 취소됩니다.
- 아이템·장비·수납칸에 커서를 두고 F를 누르면 자동 판단에서 제외하도록 잠글 수 있습니다. 빈 칸 잠금은 자동 배치가 사용하지 않는 예약 칸입니다.
- 잠긴 리그·가방·보안 컨테이너와 잠긴 아이템 내부는 자동 배치 대상으로 사용하지 않습니다.
- 검색 결과 아이템에 커서를 두고 T를 누르면 실제 Scanner와 동일한 판단 경로로 테스트 스캔할 수 있습니다.
- 레이드 종료 시 레이드 중 변경을 폐기하고 시작 시점 상태로 돌아갑니다. 레이드 중 임시 변경은 원래 프리셋을 덮어쓰지 않습니다.
- 파밍 판단은 현재 필요한 아이템을 우선하고, 필요 여부가 같으면 칸당 가치와 총가치를 비교합니다.

v1.14.1 파밍 가이드 수납 배치 안전성 수정
- product-owned exact layout은 layout identity, grid 개수와 각 grid index의 가로×세로 signature가 current Game Content와 정확히 일치할 때만 사용합니다.
- signature가 다르면 수납 mechanics는 current Game Content를 유지하면서 화면 배치만 compact fallback으로 전환합니다.

v1.14.0 파밍 가이드 조립·총기 개조·수납 배치 강화
- 총기·헬멧·방어구의 부착물 구조를 하위 부품 슬롯까지 재귀적으로 편집할 수 있습니다.
- 빈 부착물/방탄판 슬롯에서 현재 조립 상태에 맞는 아이템을 같은 화면에서 선택할 수 있습니다.
- authoritative default preset과 정확히 일치하는 조립만 composed preset 이미지를 사용합니다.

v1.13.3 파밍 가이드 인게임식 장비·수납 상호작용 수정
- 보안 컨테이너 장착 판정, nested storage drag/drop, 총기·헬멧·방어구 작업면과 base weapon 검색을 정리했습니다.
