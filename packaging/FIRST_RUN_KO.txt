준현 헬퍼 v1.7.0 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.7.0 주요 변경 — 제품 완성도·데이터 신뢰성 강화
- Scanner 인식 기록에서 해당 결과와 연결된 실제 진단 Case가 있을 때 바로 교정 화면으로 진입할 수 있습니다. 다른 프레임이나 결과를 추정으로 연결하지 않습니다.
- Scanner 교정 데이터 관리 화면에서 기존 Ground Truth와 Scanner 로그를 개발 분석용 ZIP 하나로 내보낼 수 있습니다.
- 일반 게임 데이터 업데이트에 요청별 timeout과 제한된 retry를 적용해 일시적인 네트워크·서버 오류에 대한 복원력을 높였습니다.
- 아이템·퀘스트·상인·지도·은신처·탄약·에디션의 비정상적인 대량 축소뿐 아니라 퀘스트 선행조건, 위치, 은신처 필요 아이템, 탄약 획득 조건, 한국어 이름, 아이콘·wiki metadata가 대량 소실되는 부분 데이터도 기존 정상 데이터와 비교해 차단합니다.
- 새 게임 데이터는 메모리 검증뿐 아니라 candidate DB 저장 후 실제 파일을 다시 읽어 검증한 뒤에만 활성화됩니다. 실패·취소·손상 시 기존 정상 데이터를 유지합니다.
- 동시에 여러 데이터 업데이트가 실행돼 candidate/active 파일을 서로 덮어쓰지 않도록 전체 업데이트 트랜잭션을 직렬화했습니다.
- Scanner 가격 캐시는 최고 상점가·플리 평균가·slot 정보가 비정상적으로 대량 소실되면 새 데이터로 교체하지 않습니다. Scanner가 아직 켜지지 않은 상태에서도 디스크의 같은 게임 모드 정상 캐시를 기준으로 보호합니다.
- Scanner가 Item ID를 확정한 뒤 이름/아이콘/wiki, 최고 상점가와 상인, 플리 평균가, slot당 가격, 현재 필요 개수가 모두 같은 Tarkov Item ID로 결합되는 계약을 자동 검증합니다.
- v1.6.1에서 보완한 Scanner 고급 창 DPI/글꼴 clipping 방지와 runtime 로그 7일 자동 정리 정책을 유지합니다. 사용자가 검토한 Ground Truth는 자동 삭제하지 않습니다.

Scanner 인식 안전 계약
- false positive보다 miss를 선호합니다.
- structural floor 0.34, HEADER_FRAME_LOCKED 0.68, continuous candidate cap 8, one-shot candidate cap 12를 이번 버전에서 완화하지 않았습니다.
- Item ID가 확정되기 전에는 가격·필요 개수 같은 mapped data를 identity 증거로 사용하지 않습니다.
- Scanner 인식 중 네트워크 요청, 게임 메모리 읽기, DLL injection, packet interception을 사용하지 않습니다.

사용자 데이터
- 프로필, 진행도, Scanner 설정, 교정 데이터, 로그 등 변경 가능한 사용자 데이터는 프로그램 폴더가 아니라 %LocalAppData%\JunhyunHelper 아래에 보관됩니다.
- 프로그램 업데이트로 기존 사용자 진행도와 Scanner Ground Truth를 덮어쓰지 않습니다.
