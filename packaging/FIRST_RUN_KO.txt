준현 헬퍼 v1.10.1 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.10.1 안정성 및 유지보수 감사
- 새 사용자 기능은 추가하지 않았습니다.
- 메인 헤더의 '버전만 표시 + 아이템 정리 필요 점' UI 초기화를 정적 WPF Loaded 클래스 핸들러에서 MainWindow의 명시적 제품 수명주기 초기화로 옮겼습니다.
- 헤더 상태 감시에 사용하는 DependencyPropertyDescriptor 구독을 MainWindow 종료 시 명시적으로 해제해 수명주기 소유권을 대칭적으로 정리했습니다.
- 기존 헤더 표시 방식, 아이템 정리 필요 오렌지 점의 의미, Quest/Hideout/Items/Ammo/Map/MiniMap/Scanner 사용자 동작은 변경하지 않았습니다.
- 현재 CI/Release 경로에서 사용되지 않는 v1.2.1 일회성 문서 마감 스크립트를 저장소에서 제거했습니다. 역사적 릴리즈 증거는 공식 docs에 그대로 보존됩니다.
- 배포 패키지의 FIRST_RUN_KO.txt는 현재 릴리즈에 필요한 안내와 최근 변경만 남기도록 정리했습니다. 과거 전체 변경 이력은 GitHub Release와 docs가 권위입니다.
- Scanner OCR threshold, matcher, candidate cap, visual recovery acceptance, Item ID identity policy는 변경하지 않았습니다.
- Game Content LKG/completeness/fail-closed, Map marker/Factory floor, MiniMap 동기화 계약도 변경하지 않았습니다.

v1.10.0 MiniMap 재표시 동기화 / Mini Scanner 플리마켓 최저가
- Main Map을 A에서 B로 바꾼 직후 MiniMap을 새로 열거나 숨겨져 있던 동일 MiniMap 창을 다시 표시해도 첫 visible frame부터 B를 사용하도록 수정했습니다.
- 실제 동일 MiniMap 창에서 A SVG 렌더 → hide → Main Map B 선택 → same Window show → 실제 MapSvg.Source B 렌더까지 published EXE smoke로 검증했습니다.
- Mini Scanner에 플리마켓 최저가를 추가했고 다른 정보와 동일하게 표시/숨김, 순서 변경, 설정 저장을 지원합니다.
- 플리 최저가는 Item ID 확정 후 presentation-only 데이터로만 사용하며 Scanner 인식 기준이나 scan-time network I/O에는 사용하지 않습니다.
