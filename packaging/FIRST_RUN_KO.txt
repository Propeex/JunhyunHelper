준현 헬퍼 v1.11.0 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.11.0 Scanner / Map 유지보수 및 탄약 판단
- MiniMap을 처음 켤 때 Main Map의 최신 선택이 즉시 반영되도록 첫 생성 동기화를 보강했습니다.
- 지도 Marker 설정의 탈출구 체크박스가 늦게 생성되는 경우에도 목록에 정상 반영되도록 했습니다.
- Player Marker Size 변경 뒤 MiniMap Marker Size와 Name Size 등 현재 표시 설정이 실제 렌더에 다시 적용되도록 수정했습니다.
- MiniMap marker refresh 경합으로 marker layer가 비는 경우를 감지해 한 번 복구하도록 보강했습니다.
- Scanner/Mini Scanner에서 플리마켓 최저가 표시를 제거했습니다. 내부 가격 데이터 호환성은 유지합니다.
- Hideout 요구 아이템의 FIR 여부를 실제 게임 데이터의 foundInRaid 의미대로 반영하도록 수정했습니다.
- Scanner에 설정 가능한 '교정 데이터 추가' 전역 단축키를 추가했습니다. 현재 스캔 증거를 Saved Case로 저장하며 Ground Truth는 자동 생성하지 않습니다.
- 탄약은 같은 구경의 관통력과 현재 Trader LL/해금 상태를 기준으로 '주워야 함' 여부를 판단합니다. 교환·제작·플리마켓 구매는 직접 구매 가능 탄약으로 취급하지 않습니다.
- Ammo Pack은 게임 데이터의 contained-item 관계를 우선 사용해 실제 내부 탄약으로 판단합니다.

v1.10.1 안정성 및 유지보수 감사
- 메인 헤더의 제품 수명주기 소유권과 종료 시 watcher 해제를 명시화했습니다.
- 기존 사용자-visible 기능의 의미는 유지하면서 사용되지 않는 일회성 저장소 잔재를 정리했습니다.
