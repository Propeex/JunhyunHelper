준현 헬퍼 v1.1.4 — Windows x64

실행 방법
1. 받은 ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.1.4 주요 변경 — Scanner 안정성·데이터 신뢰성 보강
- Scanner Lab v3.8의 multi-candidate semantic validation과 보수적인 matcher 기준은 그대로 유지합니다.
- 상세창 후보 안정화는 단순히 아무 후보가 두 프레임에 존재하는지만 세지 않고, 연속 관측된 동일 geometry signature가 있을 때만 누적합니다.
- 이미 안전하게 식별한 상세창은 불필요한 OCR을 반복하지 않으면서 표시 데이터만 주기적으로 다시 연결합니다.
- 이 때문에 같은 상세창을 계속 보고 있는 동안에도 Quest/Hideout 진행으로 `RequiredTotal`이 바뀌면 Mini Scanner의 '현재 필요한 수량'이 갱신됩니다.
- 표시 데이터 갱신 시 같은 로컬 아이콘 PNG를 반복해서 열고 디코딩하지 않도록 Scanner 아이콘 메모리 캐시를 추가했습니다.
- 가격 회귀 검증을 강화해 상점가는 fleaMarket을 제외한 `sellFor.priceRUB` 최고값, 플리마켓 평균가는 `avg24hPrice`를 서로 독립적으로 사용함을 고정했습니다.
- 잘못되거나 없는 가격/슬롯 데이터는 해당 표시값만 비우는 fail-closed 동작을 유지합니다.

Scanner UI
- 상단 바 왼쪽에 '스캐너'와 '테스트' 버튼이 있습니다.
- 상단 바 오른쪽의 수동 카탈로그 갱신 버튼은 '아이템 목록 최신화'입니다.
- 표시 정보 아래의 '최근 인식 기록'에서 OCR 문자열, 가장 가까운 공식 아이템 후보, 유사도, 후보 간 차이, 식별 성공/보류 판단을 확인할 수 있습니다.
- 최근 인식 기록 우측 상단의 '로그 삭제' 버튼은 화면의 인식 기록과 `%LocalAppData%\JunhyunHelper\logs\scanner.log(.1)`을 함께 삭제합니다.
- 로그 파일 삭제 실패는 Scanner 인식 자체를 중단시키지 않습니다.
- Foundation 검증 도구는 일반 Scanner 탭에서 보이지 않으며 개발 진단용 내부 경로만 유지합니다.
- Mini Scanner는 별도 편집 모드 없이 보이는 동안 직접 드래그해 위치를 옮길 수 있고, 드래그 종료 시 위치를 저장합니다.
- Mini Scanner는 Topmost/no-activate를 유지하며 게임 창의 키보드 포커스를 가져가지 않습니다.

Scanner 동작
- '스캐너 ON/OFF'는 EscapeFromTarkov 게임 창을 찾아 Borderless client-area를 대상으로 실시간 감지합니다.
- '테스트 ON/OFF'는 연결된 전체 디스플레이를 대상으로 같은 인식 파이프라인을 실행합니다. Tarkov 스크린샷을 바탕화면/이미지 뷰어에 띄운 상태에서도 기능을 확인할 수 있습니다.
- 두 모드는 동시에 실행되지 않습니다. 테스트 모드는 프로그램을 다시 실행하면 자동으로 OFF입니다.
- 실제 scan 순간에는 외부 API를 호출하지 않습니다. 아이콘도 scan 중 새로 다운로드하지 않습니다.
- 게임 메모리 읽기, DLL injection, 패킷 가로채기, 아이콘 기반 식별은 사용하지 않습니다.

Scanner 진단
- 개발자 로그: %LocalAppData%\JunhyunHelper\logs\scanner.log
- 약 2MB에서 scanner.log.1로 회전합니다.
- 구조 후보, 후보별 OCR pass, 공식 아이템 매칭 결과/confidence, 최종 선택 후보를 기록합니다.
- 전체 스크린샷이나 원본 화면 픽셀은 저장하지 않습니다.
- 실제 Tarkov 환경에서 문제가 남으면 이 로그와 Scanner 탭의 최근 인식 기록을 기준으로 detector/OCR/matcher 단계를 분리해 보정합니다.

Scanner 데이터/설정
- 전체 아이템 카탈로그: %LocalAppData%\JunhyunHelper\scanner\catalog
- Scanner 설정: %LocalAppData%\JunhyunHelper\scanner-settings.json(.bak)
- Scanner 카탈로그는 켜기/명시적 최신화/필요한 프로필 전환 시 준비하며 실제 인식 중에는 로컬/메모리 데이터만 사용합니다.
- 아이템별 표시 데이터는 확정된 Item ID를 기준으로 현재 준현 헬퍼 데이터에 연결합니다.
- 상인 판매가는 fleaMarket을 제외한 판매처의 RUB 환산 최고가입니다.
- 플리마켓 평균가는 24시간 평균가입니다.
- 현재 필요한 수량은 보유량을 빼지 않은 현재 계획의 `RequiredTotal`입니다.

프로그램 업데이트
- 새 정식 버전이 있을 때만 업데이트 확인창을 표시합니다.
- 사용자가 동의하면 새 Windows x64 ZIP과 SHA256SUMS.txt를 내려받고 검증한 뒤에만 파일을 교체합니다.
- 업데이트 확인/다운로드/검증 실패는 기존 프로그램 실행과 사용자 데이터를 손상시키지 않습니다.

배포 형태
- 설치 프로그램이 필요 없는 portable/self-contained Windows x64 빌드입니다.
- .NET/WPF/SQLite/Skia 런타임은 '준현 헬퍼.exe'에 포함됩니다.
- 지도 시스템이 경로로 직접 읽는 검증된 파일만 Assets 폴더에 둡니다.
- 실행 폴더 루트에는 '준현 헬퍼.exe', 이 안내문, Assets 폴더만 두는 것을 기준으로 합니다.
- 별도 .NET 설치나 관리자 권한은 필요하지 않습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

사용자 데이터
- 사용자 진행 데이터: %LocalAppData%\JunhyunHelper\user.db
- 게임 데이터: %LocalAppData%\JunhyunHelper\content
- 이미지 캐시: %LocalAppData%\JunhyunHelper\image-cache
- 지도 설정: %LocalAppData%\JunhyunHelper\map-product-settings.json(.bak)
- 탄약 즐겨찾기: %LocalAppData%\JunhyunHelper\ammo-favorites.json(.bak)
- Scanner 설정/카탈로그: %LocalAppData%\JunhyunHelper\scanner-settings.json(.bak), scanner\catalog\
- Scanner 진단 로그: %LocalAppData%\JunhyunHelper\logs\scanner.log(.1)
- 프로그램 파일 교체와 사용자 데이터는 분리되어 있으므로 기존 Profile / Quest / Inventory / Hideout / Map 설정 / Ammo 즐겨찾기는 유지됩니다.

데이터 호환성
