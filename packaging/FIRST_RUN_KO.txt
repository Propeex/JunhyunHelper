준현 헬퍼 v0.1.5 — Windows x64

실행 방법
1. 받은 ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.

배포 형태
- 설치 프로그램이 필요 없는 portable/self-contained Windows x64 빌드입니다.
- .NET/WPF/SQLite/Skia 런타임은 '준현 헬퍼.exe'에 묶여 있어 실행 폴더에 수많은 DLL이 나열되지 않습니다.
- 지도 시스템이 경로로 직접 읽는 검증된 파일만 Assets 폴더에 따로 둡니다.
- 실행 폴더 루트에는 '준현 헬퍼.exe', 이 안내문, Assets 폴더만 두는 것을 기준으로 합니다.
- 별도 .NET 설치나 관리자 권한은 필요하지 않습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

사용자 데이터
- 프로그램 파일과 사용자 진행 데이터는 분리됩니다.
- 사용자 진행 데이터: %LocalAppData%\JunhyunHelper\user.db
- 게임 데이터: %LocalAppData%\JunhyunHelper\content
- 이미지 캐시: %LocalAppData%\JunhyunHelper\image-cache
- 지도 제품 설정: %LocalAppData%\JunhyunHelper\map-product-settings.json
- 탄약 즐겨찾기: %LocalAppData%\JunhyunHelper\ammo-favorites.json
- 프로그램 로그: %LocalAppData%\JunhyunHelper\Logs
- 새 버전의 프로그램 파일로 교체해도 위 사용자 데이터는 자동 삭제하지 않습니다.

주요 기능
- 프로필 / 게임 모드별 진행 관리
- 퀘스트 진행과 선행 조건
- 은신처 레벨과 다음 업그레이드 재료
- 미래 퀘스트 + 은신처 기준 필요 아이템 및 보유량
- 탄약 성능 / 수급처 / 방어구 클래스 비교
- 지도 / MiniMap / 퀘스트 및 탈출구 마커
- 게임 플레이 중 사용할 수 있는 지도 전역 단축키
- 스캐너 탭(현재 준비 중)

퀘스트 상태
- '진행 중'은 준현 헬퍼가 현재 지원하는 조건만으로 해금 사실을 판정할 수 있는 퀘스트입니다.
- 서버 전역 변수, 대화 상태, 실제 게임 완료 시각 같은 정보 때문에 프로그램만으로 정확히 판정할 수 없는 퀘스트는 '확인 필요'로 따로 표시합니다.
- 실제 게임에서 해당 퀘스트를 받은 사실을 알고 있다면 '확인 필요' 상태에서도 완료/필요한 실패 동기화를 수동으로 할 수 있습니다.

지도 / MiniMap
- 지도 탭의 설정에서 단축키, 마커, MiniMap 투명도와 마커 크기 등을 조절할 수 있습니다.
- 지도 단축키는 준현 헬퍼 또는 Escape from Tarkov가 활성 창일 때 동작하도록 설계되어 있습니다.
- MiniMap은 우측 상단 고정이며 마우스로 이동/크기 조절하지 않습니다. 크기 조절은 설정한 단축키를 사용합니다.
- 선택한 층의 마커뿐 아니라 알려진 다른 층의 마커도 표시합니다.
- 같은 종류의 일반 마커가 다른 층의 비슷한 X/Z 위치에 있어도 대표 하나만 남기지 않고 각 마커를 유지합니다.
- 층 관계는 마커 주변의 작은 색상 링으로 구분합니다: 현재층=초록, 위층=빨강, 아래층=파랑. 타층에는 아주 작은 방향 표시도 보조적으로 사용합니다.
- 마커 자체의 색은 PMC/Scav/종류 같은 기존 의미를 유지하므로, 마커 본체 색과 층 링 색은 서로 다른 정보입니다.

게임 데이터 업데이트
- 상단 '데이터 업데이트'를 누르면 최신 온라인 데이터를 검증한 뒤 새 content DB를 재구축합니다.
- 업데이트 검증에 실패하면 마지막 정상 데이터를 유지합니다.
- 데이터 업데이트는 user.db의 프로필/진행/보유량을 삭제하지 않습니다.
- v0.1.4에서 v0.1.5로 올릴 때 필수 데이터 업데이트는 없습니다. 지도 런타임 패치이며 Content schema v5와 user.db schema는 그대로입니다.
- v0.1.0에서 바로 올라오는 경우에는 최신 퀘스트 판정 데이터를 위해 설치 후 '데이터 업데이트'를 한 번 실행해 주세요.

현재 범위
- 스캐너 탭은 사용자 요청에 따라 유지하지만 실제 스캐너 기능은 아직 제공하지 않습니다. 현재는 '준비 중' 안내만 표시합니다.
- 지도 artwork/config/일반 marker bundle은 현재 배포 버전에 포함된 검증된 bundle을 사용하며, Quest/Hideout/Item/Ammo 온라인 데이터 업데이트와는 별도입니다.

문제가 발생하면 어떤 화면에서 무엇을 눌렀는지, 화면에 나온 오류 문구, 사용 중이던 게임 모드와 지도/MiniMap 상태를 함께 알려주시면 원인 확인에 도움이 됩니다.
