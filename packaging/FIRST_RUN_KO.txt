준현 헬퍼 v1.3.0 — Windows x64

실행 방법
1. 받은 ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.3.0 주요 변경 — Scanner 분석·단축키 워크플로
- Scanner의 최신 인식 원본 이미지를 사용자가 원하는 위치에 PNG로 저장할 수 있습니다.
- 저장되는 PNG는 분석용 원본 캡처이며 진단 사각형/텍스트 오버레이가 합성되지 않습니다.
- 모든 연결 디스플레이를 기존 테스트 인식 파이프라인으로 한 번만 검사하는 '1회 테스트 스캔'을 추가했습니다.
- 1회 인게임 스캔, 1회 테스트 스캔, Scanner ON/OFF를 각각 전역 단축키로 사용할 수 있습니다.
- 기본 단축키는 순서대로 Ctrl+Shift+F10, Ctrl+Shift+F11, Ctrl+Shift+F12입니다.
- Scanner 탭의 '단축키 설정'에서 세 단축키를 각각 변경하거나 사용하지 않도록 설정할 수 있습니다.
- 같은 단축키를 두 Scanner 명령에 동시에 지정할 수 없습니다.
- 기존 1회 스캔 버튼은 제거했습니다. 1회 인게임/테스트 스캔은 단축키로 실행합니다.
- v1.2.x에서 변경해 둔 기존 1회 스캔 단축키는 v1.3.0에서도 인게임 1회 스캔 단축키로 우선 보존합니다.
- 기존 사용자 단축키와 새 기본키가 겹칠 경우 기존 사용자 키를 유지하고 새 명령 쪽만 비충돌 키로 조정합니다.
- OCR, 상세창 검출, Tarkov 폰트 시각 대조의 confidence/top1-top2 margin은 변경하지 않았습니다.
- 최고 상점가, 플리마켓 평균가, 필요한 개수(RequiredTotal) 계산 의미는 변경하지 않았습니다.
- Game Content schema와 user.db schema는 변경하지 않았습니다. Scanner 표시 설정 schema는 v4로 자동 승계됩니다.

Scanner 사용
- '스캐너'는 EscapeFromTarkov 게임 창의 Borderless client-area를 실시간 감지합니다.
- '테스트'는 연결된 전체 디스플레이에 같은 인식 파이프라인을 적용합니다. 실사용 Scanner와 동시에 켤 수 없습니다.
- 1회 인게임 스캔은 현재 Tarkov 화면을 한 번 정밀 분석합니다. 기본 단축키는 Ctrl+Shift+F10입니다.
- 1회 테스트 스캔은 모든 연결 디스플레이를 한 번만 정밀 분석합니다. 기본 단축키는 Ctrl+Shift+F11입니다.
- Scanner ON/OFF 단축키의 기본값은 Ctrl+Shift+F12입니다.
- 세 전역 단축키는 Scanner 탭을 보고 있지 않아도 준현 헬퍼가 실행 중이면 사용할 수 있습니다.
- '아이템 목록 최신화'는 현재 GameMode의 공식 한국어 전체 아이템 카탈로그를 갱신합니다.
- '인식 이미지'는 최신 캡처 한 장과 상세창/제목 ROI, anchor, OCR 및 최종 판단을 확인하는 진단 기능입니다.
- 인식 이미지는 기본적으로 메모리에만 유지되며 '이미지 저장'을 선택했을 때만 사용자가 지정한 PNG 파일로 저장됩니다.
- '로그 삭제'는 최근 인식 기록, %LocalAppData%\JunhyunHelper\logs\scanner.log(.1), 최신 메모리 인식 이미지를 정리합니다. 사용자가 별도로 저장한 PNG 파일은 삭제하지 않습니다.

Scanner 표시 데이터
- 최고 상점가: fleaMarket을 제외한 유효 판매처의 RUB 환산 가격 중 최댓값
- 플리마켓 평균가: positive avg24hPrice
- 상인/플리 가격·슬롯: 유효한 width × height 슬롯 수 기준
- 필요한 개수: 현재 Needed Items 계획의 RequiredTotal. 보유 Inventory를 뺀 부족량이 아닙니다.
- 가격이나 크기 정보가 누락되면 해당 표시 필드만 비우고 Item ID 식별 자체를 버리지 않습니다.

Scanner 인식 원칙
- 현재 공식 한국어 전체 아이템 카탈로그가 Item identity의 권위입니다.
- Windows ko-KR OCR 성공 경로를 우선합니다.
- OCR이 비거나 손상된 경우에만 로컬 Tarkov 제목 폰트 기반의 보수적 시각 복구를 사용합니다.
- confidence와 1·2순위 차이가 부족하면 Item ID를 확정하지 않습니다.
- 실제 스캔 순간에는 외부 API를 호출하지 않고, 아이콘도 새로 다운로드하지 않습니다.
- 게임 메모리 읽기, DLL injection, 패킷 가로채기를 사용하지 않습니다.

사용자 데이터
- 사용자 데이터는 프로그램 폴더가 아니라 %LocalAppData%\JunhyunHelper 에 저장됩니다.
- 프로그램 업데이트는 user.db, Game Content cache, 이미지 cache, Map/Ammo/Scanner 사용자 설정과 Scanner 로그를 교체하지 않습니다.

배포 형태
- Windows x64
- .NET 10 self-contained single-file
- 별도 .NET Runtime 설치 불필요
- 관리자 권한 불필요
- installer 없음

문제가 발생하면 Scanner 탭의 최근 인식 기록과 '인식 이미지'를 확인하고, 필요하면 원본 PNG를 저장해 재현 자료로 사용할 수 있습니다.
