준현 헬퍼 v1.1.6 — Windows x64

실행 방법
1. 받은 ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.1.6 주요 변경 — Scanner 아이템 목록 동기화 회귀 수정
- v1.1.5에서 상인 가격 데이터의 전체 커버리지를 아이템 식별 카탈로그의 정상 조건으로 잘못 묶어, 이름/ID가 정상이어도 '아이템 목록 최신화'가 실패할 수 있던 문제를 수정했습니다.
- Scanner 카탈로그의 필수 건강성은 공식 Item ID와 공식 이름의 완전성으로 판정합니다. 4,000개 미만이거나 ID/이름이 손상된 카탈로그는 계속 거부합니다.
- 상인 가격이나 플리 가격이 없거나 일부 누락된 경우에는 카탈로그 전체를 막지 않고 해당 가격 표시만 비우는 field-level fail-closed 동작을 사용합니다.
- raw traderPrices와 sellFor 가격 형태 지원은 그대로 유지합니다.
- 수동 '아이템 목록 최신화' 결과는 scanner.log에 outcome, 전체 아이템 수, 상인 가격 보유 아이템 수, 플리 가격 보유 아이템 수를 기록해 다음 장애를 원인별로 확인할 수 있습니다.
- Game Content schema와 user.db schema는 변경하지 않습니다.

v1.1.5 주요 변경 — Mini Scanner/시장 데이터/아이콘 안정화
- Mini Scanner는 아이템 식별이 성공했을 때 해당 아이템 정보만 표시합니다. 대기·OCR·오류·진단 상태 문구는 Mini Scanner에 표시하지 않습니다.
- 실제 Scanner에서는 Tarkov가 포그라운드이고 한국어 인벤토리/창고 UI가 확인될 때만 Mini Scanner를 표시합니다. 확신이 없으면 표시하지 않는 fail-closed 방식입니다.
- Mini Scanner는 WPF Topmost와 Windows HWND_TOPMOST를 함께 적용하고 키보드 포커스를 가져가지 않습니다.
- Mini Scanner 내부 사각형 전체가 드래그 영역이며 글자나 아이콘을 정확히 집을 필요가 없습니다.
- 드래그 중에도 마우스 포인터는 일반 화살표를 유지합니다.
- 기존 사용자 설정을 1회 보정해 아이콘, 상인 가격, 상인 가격/슬롯 표시를 기본 활성화합니다. 이후 사용자가 직접 끈 항목은 새 설정으로 보존됩니다.
- Scanner 가격 데이터는 현재 JSON 원본의 traderPrices와 파생 sellFor 형태를 모두 읽습니다.
- 플리 평균가는 avg24hPrice를 독립적으로 사용합니다.
- Game Content 업데이트 시 퀘스트/은신처/탄약에 한정하지 않고 공식 전체 아이템 아이콘을 로컬 캐시에 준비합니다. 실제 스캔 순간에는 다운로드하지 않습니다.
- 아이템 제목 OCR과 인벤토리 화면 판별 OCR은 하나의 직렬화된 OCR 경계를 공유해 동시 OCR 경쟁을 방지합니다.

Scanner UI
- 상단 바 왼쪽에 '스캐너'와 '테스트' 버튼이 있습니다.
- 상단 바 오른쪽의 수동 카탈로그 갱신 버튼은 '아이템 목록 최신화'입니다.
- 표시 정보 아래의 '최근 인식 기록'에서 OCR 문자열, 가장 가까운 공식 아이템 후보, 유사도, 후보 간 차이, 식별 성공/보류 판단을 확인할 수 있습니다.
- 최근 인식 기록 우측 상단의 '로그 삭제' 버튼은 화면의 인식 기록과 `%LocalAppData%\JunhyunHelper\logs\scanner.log(.1)`을 함께 삭제합니다.
- Mini Scanner에는 이 진단/상태 내용이 나오지 않습니다.

Scanner 동작
- '스캐너 ON/OFF'는 EscapeFromTarkov 게임 창을 찾아 Borderless client-area를 대상으로 실시간 감지합니다.
- 실제 Mini Scanner 표시 조건은 '아이템 식별 성공 + Tarkov 포그라운드 + 인벤토리/창고 UI 확인'입니다.
- 인벤토리/창고 판별은 화면 픽셀과 Windows 한국어 OCR만 사용합니다. 게임 메모리, DLL injection, 패킷 가로채기를 사용하지 않습니다.
- '테스트 ON/OFF'는 연결된 전체 디스플레이를 대상으로 같은 아이템 인식 파이프라인을 실행하며 개발/표시 검증을 위해 인벤토리 화면 제한을 적용하지 않습니다.
- 두 모드는 동시에 실행되지 않습니다. 테스트 모드는 프로그램을 다시 실행하면 자동으로 OFF입니다.
- 실제 scan 순간에는 외부 API를 호출하지 않습니다. 아이콘도 scan 중 새로 다운로드하지 않습니다.

Scanner 가격/수량
- 상인 판매가 = fleaMarket을 제외한 판매처의 RUB 환산 최고가입니다.
- 상인 가격/슬롯 = 상인 판매가를 유효한 아이템 슬롯 수로 나눈 값입니다.
- 플리마켓 평균가 = 24시간 평균가(avg24hPrice)입니다.
- 현재 필요한 수량 = 보유량 차감 부족량이 아니라 현재 계획의 NeededItems[].RequiredTotal입니다.
- 잘못되거나 없는 가격/크기 데이터는 해당 표시값만 비우는 fail-closed 동작을 유지합니다.

아이콘 캐시
- Game Content 업데이트 시 공식 전체 아이템 아이콘을 `%LocalAppData%\JunhyunHelper\image-cache`에 준비합니다.
- 이미 정상적으로 캐시된 아이콘은 다시 다운로드하지 않습니다.
- 개별 이미지 실패는 전체 Game Content 업데이트를 망가뜨리지 않으며 다음 업데이트에서 다시 채울 수 있습니다.

Scanner 진단
- 개발자 로그: %LocalAppData%\JunhyunHelper\logs\scanner.log
- 약 2MB에서 scanner.log.1로 회전합니다.
- 구조 후보, 후보별 OCR pass, 공식 아이템 매칭 결과/confidence, 최종 선택 후보와 인벤토리 화면 판별 결과를 기록합니다.
- 수동 카탈로그 동기화는 `catalog-sync` 이벤트로 success/outcome/items/traderPrices/fleaPrices/기존 캐시 사용 여부를 기록합니다.
- 전체 스크린샷이나 원본 화면 픽셀은 저장하지 않습니다.

프로그램 업데이트
- 새 정식 버전이 있을 때만 업데이트 확인창을 표시합니다.
- 사용자가 동의하면 새 Windows x64 ZIP과 SHA256SUMS.txt를 내려받고 검증한 뒤에만 파일을 교체합니다.
- 업데이트 확인/다운로드/검증 실패는 기존 프로그램 실행과 사용자 데이터를 손상시키지 않습니다.

배포 형태
- 설치 프로그램이 필요 없는 portable/self-contained Windows x64 빌드입니다.
- .NET/WPF/SQLite/Skia 런타임은 '준현 헬퍼.exe'에 포함됩니다.
- 지도 시스템이 경로로 직접 읽는 검증된 파일만 Assets 폴더에 둡니다.
- 실행 폴더 루트에는 '준현 헬퍼.exe', 이 안내문, Assets 폴더만 두는 것을 기준으로 합니다.
- 별도 .NET 설치나 관리자 권한은 필요하지 않습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

사용자 데이터
- 사용자 진행 데이터: %LocalAppData%\JunhyunHelper\user.db
- 게임 데이터: %LocalAppData%\JunhyunHelper\content
- 이미지 캐시: %LocalAppData%\JunhyunHelper\image-cache
- 지도 설정: %LocalAppData%\JunhyunHelper\map-product-settings.json(.bak)
- 탄약 즐겨찾기: %LocalAppData%\JunhyunHelper\ammo-favorites.json(.bak)
- Scanner 설정/카탈로그: %LocalAppData%\JunhyunHelper\scanner-settings.json(.bak), scanner\catalog\
- Scanner 진단 로그: %LocalAppData%\JunhyunHelper\logs\scanner.log(.1)
- 프로그램 파일 교체와 사용자 데이터는 분리되어 있으므로 기존 Profile / Quest / Inventory / Hideout / Map 설정 / Ammo 즐겨찾기는 유지됩니다.

데이터 호환성
- Content schema: v7
- Readable Content schemas: v3, v4, v5, v6, v7
- user.db SQLite schema: v1
- v1.1.5 → v1.1.6 필수 Game Content schema 업데이트: 없음
- v1.1.5 → v1.1.6 user.db migration: 없음
- Scanner 표시 설정은 내부 schema v2를 유지합니다.
- 기존 Scanner 카탈로그 cache schema v1/v2를 그대로 읽습니다.
