준현 헬퍼 — 첫 실사용 테스트 빌드

실행 방법
1. ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. JunhyunHelper.exe를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 게임 데이터를 온라인에서 내려받습니다.

중요
- 설치 프로그램이 없는 테스트 빌드입니다. 관리자 권한은 필요하지 않습니다.
- 프로그램 파일을 다른 폴더로 옮기거나 새 버전으로 교체해도 사용자 진행 데이터는 프로그램 폴더 안에 저장되지 않습니다.
- 사용자 진행 데이터 기본 위치: %LocalAppData%\JunhyunHelper\user.db
- 다운로드된 게임 데이터 기본 위치: %LocalAppData%\JunhyunHelper\content
- 프로필 삭제를 누르지 않는 한 새 버전 실행 파일로 교체했다고 user.db를 자동 삭제하지 않습니다.
- 이 빌드는 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

테스트 중 확인하면 좋은 것
- 프로필 생성/수정/전환이 자연스러운지
- 퀘스트 상태와 완료/취소 동작이 실제 플레이 흐름과 맞는지
- 은신처 레벨 입력이 편한지
- 아이템 필요/충분/정리 필요/판단 보류 분류가 이해하기 쉬운지
- FIR/일반 보유량 입력이 실제 사용에서 얼마나 번거로운지
- 탄약 검색/구경 필터/표가 보기 편한지
- 데이터 업데이트 후 기존 진행과 보유량이 그대로 유지되는지

문제가 발생하면 어떤 화면에서 무엇을 눌렀는지와 화면에 나온 오류 문구를 알려주시면 됩니다.
