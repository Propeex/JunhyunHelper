준현 헬퍼 v1.8.3 — Windows x64

실행 방법
1. 받은 'Junhyun-Helper.zip'을 원하는 위치에 압축 해제합니다.
2. 압축을 풀면 생성되는 '준현 헬퍼' 폴더 안의 '준현 헬퍼.exe'를 실행합니다.
3. 처음 실행하면 프로필을 만들고 필요한 최신 게임 데이터를 온라인에서 내려받습니다.
4. 프로그램 실행 시 GitHub의 최신 정식 준현 헬퍼 릴리즈를 확인합니다. 더 최신 버전이 있으면 업데이트 여부를 묻습니다.

v1.8.3 탄약 / 지도 UI 실사용 회귀 수정
- 탄약 탭의 구경 및 즐겨찾기 선택 UI가 실제 공개 실행 파일에서도 페이지 초기화와 함께 확실히 적용되도록 수정했습니다.
- 즐겨찾기 선택은 일반 드롭다운을 사용하며, 구경 드롭다운과 동일한 구경별 탄약 아이콘 및 순환 애니메이션을 공유합니다.
- 기존 즐겨찾기 메뉴가 새 드롭다운 대신 남는 경우를 차단하고, 공개 실행 파일 검증이 실제 초기화 누락을 뒤늦게 보정해 숨기지 못하도록 검증 순서를 강화했습니다.
- 지도 마커 선택 창의 체크박스 영역이 헤더를 제외한 남은 세로 공간 전체를 사용하도록 수정했습니다.
- 체크박스가 현재 패널 안에 모두 들어가면 불필요한 세로 스크롤바를 표시하지 않고, 실제로 내용이 넘칠 때만 자동으로 표시합니다.
- 지도 마커 패널 초기화가 WPF의 일시적인 부모 관계나 routed Loaded 이벤트의 세부 발생 방식에 의존하지 않도록 수정했습니다.
- 기존 지도, Factory 층 표시, MiniMap, 지도 마커 기능 의미는 변경하지 않았습니다.

v1.8.2 런타임 UI / 실시간 Game Content 회귀 수정
- 탄약 탭의 구경 및 즐겨찾기 드롭다운 초기화를 WPF 타입 초기화 순서에 의존하지 않도록 고정해, 공개 빌드에서도 구경별 탄약 아이콘과 동일한 순환 애니메이션이 실제로 표시되도록 수정했습니다.
- 공개 실행 파일 smoke가 구경 드롭다운과 즐겨찾기 드롭다운의 실제 렌더링 Image, 동일 아이콘 상태, 타이머 순환까지 검증하도록 강화했습니다.
- json.tarkov.dev가 Bitcoin Farm의 수동 재료 없는 생산 항목을 일반 craft처럼 제공하는 현재 형식을 명시적으로 구분해, 잘못된 제작 관계를 Scanner 아이템 DB에 만들지 않도록 수정했습니다.
- json.tarkov.dev가 동일한 상인 구매 offer를 중복 제공하는 경우 canonical 관계 모델에서 완전히 동일한 record만 정규화해 중복 수급처 생성을 방지합니다.
- 다른 빈 craft, 서로 다른 상인 offer, 관계 참조/가격/수량 무결성, 기존 LKG/completeness fail-closed 계약은 그대로 유지합니다.
- Scanner OCR/아이템 인식 임계값, matcher, visual recovery 정책은 변경하지 않았습니다.

v1.8.1 Game Content 관계 데이터 안전성 보강
- v1.8.0에서 추가된 Scanner 아이템 정보 DB의 상인 구매·상인 교환·은신처 제작·플리마켓 관계도 기존 Game Content와 동일한 50% LKG shrink guard로 보호합니다.
- 정상 관계 데이터가 이미 있는 상태에서 upstream이 구조적으로 정상인 채 관계를 절반 미만으로 누락하면 새 candidate를 적용하지 않고 기존 정상 데이터를 유지합니다.
- 교환/제작의 관계 개수뿐 아니라 내부 재료 목록의 대량 누락도 별도로 감시합니다.
- v8+ 새 데이터에서 상인 구매·교환·제작·플리마켓 관계 집합이 통째로 비어 있으면 fail closed합니다.
- 저장된 candidate를 다시 읽을 때와 실제 active snapshot을 검증할 때도 관계 무결성 검사를 반복합니다.
- v3~v7 구형 snapshot은 관계 그래프가 없다는 사실을 정상적인 legacy 상태로 계속 읽을 수 있습니다.

v1.8.0 Scanner 아이템 정보 DB
- Scanner 아이템 검색 상세에서 종류, 크기, 무게, 플리마켓 거래 가능 여부, 기본 가격을 확인할 수 있습니다.
- 퀘스트, 은신처 업그레이드, 제작, 상인 교환에서 해당 아이템이 사용되는 곳을 기능별로 확인할 수 있습니다.
- 상인 현금 구매는 가격, 화폐, 충성도 레벨, 구매 제한, 제공되는 재고 갱신 시각 정보를 표시합니다.
- 상인 교환과 은신처 제작은 필요한 재료와 수량, 결과 수량을 표시하며 제작은 제작 시간과 비소모 도구도 구분합니다.
- 수급처는 상인 구매, 상인 교환, 은신처 제작, 플리마켓, 레이드 획득을 구분합니다.
- 제작·교환 재료와 결과 아이템을 클릭하면 같은 Scanner 아이템 상세로 이동할 수 있습니다.
- 관계 데이터는 게임 데이터 업데이트 때 검증·저장되며 Scanner 검색 중 별도 네트워크 요청을 하지 않습니다.

v1.7.15 UI 마무리
- 메인 상단 상태 영역은 버전 정보만 표시합니다. 정리가 필요한 아이템이 있으면 아이템 탭 우측 상단의 작은 주황색 점으로 알려줍니다.
- 지도 마커 선택 창의 체크박스 목록이 실제 가용 세로 공간을 사용하도록 수정했습니다.
- 지도 마커 선택 창은 창 바깥의 지도/빈 영역을 클릭해도 닫히며 원래 지도/컨트롤 동작은 유지합니다.
- 탄약 탭의 즐겨찾기 선택을 일반 드롭다운으로 변경했습니다.
- 구경 및 즐겨찾기 드롭다운은 각 구경에 속한 탄약 아이콘을 같은 순서와 타이밍으로 순환 표시합니다.

이전 버전의 상세 변경 내역과 검증 기록은 GitHub Releases 및 저장소의 docs 릴리즈 문서를 기준으로 확인합니다.
